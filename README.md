# ScanFood v1

![Estado](https://img.shields.io/badge/Estado-En%20construcción-orange)

Aplicación nativa en PHP para escanear información nutricional y aditivos alimentarios.

## Diario de aprendizaje
Sigue mi progreso y notas técnicas en el [Diario de Aprendizaje](docs/diario.md).

## Instalación y Configuración

1. Clona este repositorio.
2. Duplica el archivo `config_local.example.php` y renómbralo a `config_local.php`.
3. Edita `config_local.php` con las credenciales de tu servidor MariaDB.
4. Importa los archivos de la carpeta `sql/` para crear la base de datos y los datos de prueba.
